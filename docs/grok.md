# Retired direct xAI and Grok subscription integration

Catalyst no longer supplies `xai` or `grok-subscription` profiles, reads Grok login
files, accepts `--grok-auth-file`, or bundles a stock Grok harness. Historical
results remain readable; new runs must use an available runtime provider.

See [model access](live-models.md#implemented-providers-and-hosted-permission)
for the current provider contract and hosted rollout status. Dungeness owns the
trusted gateway registry; Catalyst does not add providers during preparation.
