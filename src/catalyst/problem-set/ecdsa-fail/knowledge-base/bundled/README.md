# Licensed paper copies

These 40 PDFs are the complete, unmodified `ecdsa-papers-v2` library, including
the required [Schrottenloher paper](https://arxiv.org/abs/2606.02235v1). They ship
with both the source checkout and Python package, so preparing this library
requires no external downloads. Total PDF size is about 52 MB.

Author attribution, original sources, individual license URLs and SHA-256 hashes
are in [`../v2.json`](../v2.json). License evidence is recorded in
[`../licenses-v2.json`](../licenses-v2.json). Preserve these notices when copying
the papers. Each paper's own license applies, separately from the Catalyst
software license.
