# Licensed paper copies

These eight PDFs are the complete, unmodified `ecdsa-papers-v1` library, including
the required [Schrottenloher paper](https://arxiv.org/abs/2606.02235v1). They ship
with both the source checkout and Python package, so preparing this library
requires no external downloads. Total PDF size is about 9.8 MiB.

Author attribution, original sources, individual license URLs and SHA-256 hashes
are in [`../v1.json`](../v1.json). License evidence is recorded in
[`../licenses-v1.json`](../licenses-v1.json). Preserve these notices when copying
the papers. Each paper's own license applies, separately from the OpenRSI
software license.
